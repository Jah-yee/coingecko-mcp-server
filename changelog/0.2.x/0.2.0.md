# 0.2.0 — 2026-10-15

## Added

- **Market ID selection** supports portfolio tables with normalized IDs, applied-selector metadata, and empty-page guidance; choose either IDs or category, since combined selectors fail with `conflicting_filters` ([#15](https://github.com/cyanheads/coingecko-mcp-server/issues/15)).

## Changed

- **Chart pagination** returns 100 exact points per series by default, capped at 250; migrate complete-history consumers to `point_offset`/`point_limit` and follow `nextPointOffset`. Both response surfaces render every returned observation; subsequent pages refetch upstream ([#6](https://github.com/cyanheads/coingecko-mcp-server/issues/6)).
- **Chart cadence** replaces `minutely` with measured `5-minute`, `hourly`, `daily`, `irregular`, or `unknown`, computed before pagination; `observedIntervalInMs` exposes median positive timestamp spacing ([#11](https://github.com/cyanheads/coingecko-mcp-server/issues/11)).
- **Chart interval selection** forwards explicit `daily`/`hourly` requests; the research prompt requests daily observations for its 30-day overview.
- **Development guidance** synchronizes framework schema repair, bounded diagnostics, canvas, and release instructions; portable MCPB bundles omit source, tests, scripts, agent documentation, and test caches.

## Fixed

- **Malformed-response contract** advertises the emitted `ServiceUnavailable` code while preserving transient retries ([#2](https://github.com/cyanheads/coingecko-mcp-server/issues/2)).
- **Category discovery** preserves the complete unfiltered catalog and reports its actual count with narrowing examples ([#5](https://github.com/cyanheads/coingecko-mcp-server/issues/5)).
- **Market sorting** accepts the six supported market-cap, volume, and ID orders; unsupported price-change orders fail before fetching ([#8](https://github.com/cyanheads/coingecko-mcp-server/issues/8)).
- **Transport recovery** distinguishes permanent refusals, timeouts, rate limits, and transient failures, retaining framework retry decisions and bounded sanitized JSON explanations; history-limit errors recommend a narrower window ([#9](https://github.com/cyanheads/coingecko-mcp-server/issues/9)).
- **Demo history limits** accept 1–365 days, map `max` to 365 with disclosure, and reject inverted ranges while preserving valid future endpoints ([#10](https://github.com/cyanheads/coingecko-mcp-server/issues/10)).
- **Coin percentage changes** select the requested currency across every window, omit missing/null metrics, and preserve zero. Conditional supported-currency validation and the primary request share a 50-second deadline; profile-only requests skip validation ([#12](https://github.com/cyanheads/coingecko-mcp-server/issues/12)).
- **ID and currency normalization** trims/lowercases inputs, bounds batches to 500 raw/250 unique processed IDs, distinguishes skipped IDs from misses and missing quotes, and decodes coin-resource URI escapes once before normalization ([#13](https://github.com/cyanheads/coingecko-mcp-server/issues/13)).
